# Utility Examples

This folder contains general helper utilities and simulation support scripts.

## Scripts

- `generate_trajectories.py`
- `record_simulation_gif.py`
- `run_simulation_optimization_adam.py`
- `run_simulation_optimization_cma_es.py`
- `run_simulation_optimization_SGD.py`

## Typical commands

```powershell
python .\examples\utilities\generate_trajectories.py --help
python .\examples\utilities\record_simulation_gif.py --help
python .\examples\utilities\run_simulation_optimization_adam.py --help
```

## Expected outputs

- generated trajectory rollouts
- GIF previews
- optimization logs and parameter-search outputs
